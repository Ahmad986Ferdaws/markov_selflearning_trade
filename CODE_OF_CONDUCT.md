# Code of conduct

This is a one-maintainer research repository whose product is a set of numbers and the
caveats around them. The rules below exist so that arguing about those numbers stays useful.

## Expected

- Be specific. Quote the line, the test, or the result file you are talking about.
- Be civil. Critique the method, the data, or the code, not the person who wrote it.
- Disclose a conflict when you assert a number. If you run, sell, or are paid to promote a
  strategy the finding bears on, say so in the same comment.
- Accept a correction once it is shown. Repeating a claim after it has been answered with a
  reproducible check, and without new evidence, is not disagreement.

## Not accepted

- Harassment, insults, or discriminatory remarks of any kind.
- Publishing someone's private information: addresses, keys, account details, private
  messages, anywhere in this repository.
- Bad-faith methodology claims: a number or a lookahead accusation repeated after it was
  corrected with a reproducible check and no new evidence was offered.

## Scope

Issues, pull requests, discussions, review comments, and any other space GitHub attaches to
this repository.

## Enforcement

The maintainer may edit, hide, lock, or remove content and may block repeat offenders.
Report a problem through the private vulnerability form on the Security tab (it reaches only
the maintainer) or by email to the address on the maintainer's GitHub profile. Expect an
acknowledgement within a week; this is a one-maintainer project.

This document applies to the maintainer too. If the maintainer breaks it, say so in the
thread or by the same private route.
